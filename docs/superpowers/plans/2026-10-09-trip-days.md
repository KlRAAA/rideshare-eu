# Trip Days Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Drivers confirm or skip individual trip days; the app asks the evening before, warns riders when a driver hasn't confirmed or started, and records no-shows.

**Architecture:** `TripRun` gains `CONFIRMED`, `SKIPPED`, `NO_SHOW`. Pure timing rules in `server/services/tripDayRules.js`; `server/services/tripDayService.js` holds the day routes' logic and `settleTrips(trips, now)` — the per-trip automatic steps, run by the 5-minute job and on reads (replacing `applyLazyCompletion`). Routes live in `tripRunController.js`.

**Tech Stack:** Express 5, Prisma 7 (`db push`), Next.js 16 / React 19, Jest 30.

**Spec:** `docs/superpowers/specs/2026-10-09-trip-days-design.md`

## Global Constraints

- Ask at 8 PM Philippine time the evening before; only when the day has approved or pending riders and the trip existed before that 8 PM.
- Unconfirmed warning at departure − 60 min (only if the driver was asked); late warning at + 15 min; no-show at + 60 min; start window closes at + 60 min.
- No-show only with approved riders; no automatic strike or trust-score change.
- Skip only for recurring trips; undo until that day's departure.
- Every notification from these steps carries `occurrenceDate` = the run day and is never created twice for the same type, user, trip and day.
- `NO_SHOW_CANCEL_REASON = "The driver didn't start the trip"`; such cancellations don't count as host cancellations on the watch list.
- Schema changes additive/loosening only; back up dev and demo first.

```js
// When the automatic steps for a trip day happen (sub-project D). Pure.
const { departureOnDay } = require('./tripRunRules');
const { phDateOnly } = require('./recurrenceMath');

const DAY_MS = 24 * 60 * 60 * 1000;
const MIN_MS = 60 * 1000;
const UNCONFIRMED_BEFORE_MS = 60 * MIN_MS;
const LATE_AFTER_MS = 15 * MIN_MS;
const NO_SHOW_AFTER_MS = 60 * MIN_MS;
const ASK_HOUR_PH = 20;

// 8 PM Philippine time on the day before `day` (a PH date as phDateOnly gives it).
function askAt(day) {
  return new Date(day.getTime() - DAY_MS + (ASK_HOUR_PH - 8) * 60 * MIN_MS);
}

function dueSteps(departure, now) {
  const t = now.getTime();
  const d = departure.getTime();
  return {
    unconfirmedWarning: t >= d - UNCONFIRMED_BEFORE_MS && t < d,
    lateWarning: t >= d + LATE_AFTER_MS && t < d + NO_SHOW_AFTER_MS,
    noShow: t >= d + NO_SHOW_AFTER_MS,
  };
}

// The next `count` days the trip runs, from today (PH) on, whose departure hasn't passed.
function upcomingDays(trip, now, count) {
  const out = [];
  const today = phDateOnly(now);
  for (let i = 0; out.length < count && i < 60; i++) {
    const day = new Date(today.getTime() + i * DAY_MS);
    const departure = departureOnDay(trip, day);
    if (departure && departure > now) out.push({ day, departure });
  }
  return out;
}

module.exports = { askAt, dueSteps, upcomingDays, UNCONFIRMED_BEFORE_MS, LATE_AFTER_MS, NO_SHOW_AFTER_MS };
```

```js
async function settleTrips(trips, now = new Date()) {
  const active = trips.filter((t) => t.status === 'OPEN' || t.status === 'FULL');
  if (active.length === 0) return trips;
  const today = phDateOnly(now);
  const days = [new Date(today - DAY_MS), today, new Date(today.getTime() + DAY_MS)];
  const runs = await prisma.tripRun.findMany({ where: { tripId: { in: active.map((t) => t.id) }, runDate: { in: days } } });
  const runOf = new Map(runs.map((r) => [`${r.tripId}:${r.runDate.getTime()}`, r]));
  for (const trip of active) {
    const matches = Array.isArray(trip.matches) ? trip.matches : await prisma.match.findMany({ where: { tripId: trip.id } });
    for (const day of days) {
      const departure = departureOnDay(trip, day);
      if (!departure) continue;
      await settleDay({ ...trip, matches }, day, departure, runOf.get(`${trip.id}:${day.getTime()}`) ?? null, now, trip);
      if (trip.status !== 'OPEN' && trip.status !== 'FULL') break;
    }
  }
  return trips;
}
```
