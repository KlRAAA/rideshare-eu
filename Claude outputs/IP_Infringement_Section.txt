Map Data and Routing

Map rendering and route geometry are provided by Mapbox GL JS and the Mapbox Directions API, used under Mapbox's commercial free tier, which permits this volume of usage without a paid subscription while remaining bound by the Mapbox Terms of Service. Mapbox GL JS is distributed under Mapbox's own proprietary license (not an open-source license — see mapbox-gl's LICENSE.txt), which authorizes use only in conjunction with an active Mapbox account and only through Mapbox's own services; the underlying map data displayed through Mapbox is itself sourced in part from OpenStreetMap contributors.

Forward and reverse geocoding (converting a typed address to coordinates and back) is provided by OpenStreetMap's Nominatim service, whose data is licensed under the Open Database License (ODbL) and whose usage policy requires a descriptive, non-generic User-Agent header identifying the requesting application and prohibits unbounded automated bulk queries. RideShareEU complies with this by sending the literal header value "RideShareEU-MSEUF-Thesis-Prototype/1.0" on every Nominatim request (server/services/geocodingService.js) and by issuing geocoding calls only in direct response to a single user action (typing an address, confirming a pin), never as a batch job.
